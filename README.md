# Enterprise SAS to Python Migration

## Overview

This project demonstrates the migration of enterprise SAS ETL processes to Python.

It is designed as a real-world healthcare data warehouse project and includes:

- Healthcare data generator
- SAS ETL programs
- Python migration
- Data validation framework
- SQL examples
- Airflow orchestration
- Unit testing
- Performance optimization
